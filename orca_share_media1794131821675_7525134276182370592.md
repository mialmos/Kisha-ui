# Kisha

A compact, mobile-friendly Roblox Luau UI library. Single file, no telemetry, no remote services.

## Install

```lua
local Kisha = loadstring(game:HttpGet("YOUR_RAW_URL_TO_Kisha.lua"))()
```

## Quick start

```lua
local Window = Kisha:CreateWindow({
    Title = "Kisha",
    Subtitle = "optional",
    Accent = Color3.fromRGB(62, 112, 255), -- optional
    ToggleKey = Enum.KeyCode.RightControl,
    Size = UDim2.fromOffset(560, 420),
})

local Tab = Window:CreateTab({ Name = "Main", Icon = "★" })
local Section = Tab:CreateSection({ Name = "Movement" })

Section:AddToggle({ Name = "Example", Default = false, Flag = "example_toggle", Callback = function(v) end })
Section:AddSlider({ Name = "Speed", Min = 0, Max = 100, Default = 10, Increment = 1, Flag = "speed", Callback = function(v) end })
Section:AddDropdown({ Name = "Mode", Options = { "A", "B", "C" }, Default = "A", Flag = "mode", Callback = function(v) end })
Section:AddButton({ Name = "Run", Callback = function() end })
Section:AddKeybind({ Name = "Menu Key", Default = Enum.KeyCode.RightControl, Callback = function(key) end })
Section:AddTextbox({ Name = "Input", Placeholder = "...", Default = "", Callback = function(text) end })
Section:AddParagraph({ Title = "Info", Body = "..." })

Kisha:Notify({ Title = "Kisha", Content = "Loaded", Duration = 3 })
```

All methods accept both `:` and `.` call styles.

## API

**Library**
- `CreateWindow(opts)`: `Title`, `Subtitle`, `Accent`, `ToggleKey`, `Size`, `MobileButton` (force/disable the on-screen launcher; auto on touch-only devices)
- `Notify({ Title, Content, Duration })`
- `SaveConfig(name)` / `LoadConfig(name)`: returns `true`/`false`. Uses `writefile`/`readfile`/`isfile` when present, otherwise safely returns `false`. Files go in `Library.ConfigFolder` (`Kisha/configs`).
- `ConfigHooks.Save(name, json)` / `ConfigHooks.Load(name) -> json`: optional custom storage
- `Flags`: table mirroring every element that has a `Flag`
- `Destroy()`: removes everything and disconnects all connections

**Window**: `CreateTab`, `SetVisible(bool)`, `Toggle()`, `SetToggleKey(key)`, `SetAccent(Color3)`, `Destroy()`

**Tab**: `CreateSection({ Name })`

**Elements** (return an object with `Set(value, silent?)`, `Get()`, `Destroy()` where relevant)
- Toggle, Slider (`Suffix` optional), Dropdown (`Refresh(options, keepValue)`), Button (`SetText`), Keybind, Textbox (`ClearOnFocus` optional), Paragraph (`Set(title, body)`)

**Keybind extras**
- `BindToggle = true`: rebinding also changes the window's toggle key
- `Pressed = function() end`: runs when the bound key is pressed
- In the keybind box: Esc cancels, Backspace clears

## Notes
- ScreenGui is `KishaUI`, parented to CoreGui when allowed, else PlayerGui.
- Re-running the script tears down the previous instance first.
- Window scales down automatically on small screens; slider drags disable page scrolling while active.
